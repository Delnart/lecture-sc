# 💡 Лекція «Хто така Студрада ФІОТ» — Telegram Bot

Офіційний Telegram-бот реєстрації учасників на лекцію **«Хто така Студрада ФІОТ»** від Студентської ради факультету інформатики та обчислювальної техніки (ФІОТ) КПІ ім. Ігоря Сікорського.

## 📌 Інформація про захід

- **Тема:** Хто така Студрада ФІОТ (структура СР ФІОТ, департаменти, студентські ініціативи та можливості розвитку).
- **Дата і час:** 4 жовтня о 14:00.
- **Формати присутності:**
  - 📍 **Офлайн:** [18 корпус КПІ ім. Ігоря Сікорського](https://maps.app.goo.gl/Xf2p69hudhib6iSz7?g_st=ic)
  - 💻 **Онлайн:** [Трансляція на YouTube Студради ФІОТ](https://www.youtube.com/@studentcouncilfice)
- **Після лекції:** Відкриття офіційного набору до команди Студради ФІОТ!
- **Анонси та новини:** [FICE Time 🇺🇦](https://t.me/fice_time)
- **Відео-анонс:** [Дивитись анонс](https://serv1.vlix.io/media/videos/h264/a9eef9bba69c7d4e8710.mp4)

## 🚀 Основні можливості

- **Покрокова реєстрація учасників:**
  - Введення ПІБ та контактних даних (Telegram username).
  - Введення академічної групи з перевіркою належності до ФІОТ.
  - **Вибір формату присутності:** 📍 **Офлайн** (18 корпус) або 💻 **Онлайн** (трансляція на YouTube).
  - Ознайомлення та погодження з правилами заходу.
  - Екран підтвердження з відображенням усіх даних.
- **Особистий профіль:**
  - Перегляд збережених реєстраційних даних та поточного формату участі.
  - **Можливість будь-коли змінити формат участі (онлайн/офлайн)** в один клік.
  - Редагування будь-яких полів профілю (ПІБ, нікнейм, група).
- **Розділ «Часті питання» (FAQ):**
  - Динамічне завантаження з `app/data/faq_data.csv`.
  - Відповіді про локацію, час, онлайн-трансляцію, набір у Студраду та зміну формату.
  - Швидкі кнопки переходу на YouTube та Google Maps прямо у повідомленні з відповіддю.
- **Панель адміністратора:**
  - Відкриття / закриття реєстрації в реальному часі.
  - **Таргетовані розсилки за форматом:**
    - 📢 Всім зареєстрованим учасникам
    - 📍 Тільки офлайн-учасникам (наприклад, номер аудиторії чи інструкції для входу)
    - 💻 Тільки онлайн-учасникам (наприклад, пряме посилання на YouTube трансляцію)
    - 🎯 Конкретним користувачам за @username або Telegram ID
    - 👥 Студентам інших факультетів (якщо вказали не ФІОТ)
  - Керування заблокованими користувачами та скасування реєстрації.
  - Швидкий перехід до Google Таблиці з базою учасників.
- **Інтеграція з Google Sheets:**
  - Автоматичне внесення учасників із зазначенням формату (колонка G).
  - Синхронізація змін профілю та формату в режимі реального часу.
  - Видалення рядків при скасуванні реєстрації або блокуванні.

## 🛠 Технологічний стек

- **Мова:** Python 3.12+
- **Фреймворк:** [aiogram 3.x](https://docs.aiogram.dev/)
- **База даних:** PostgreSQL (Neon Serverless / Docker) через [SQLAlchemy 2.0](https://www.sqlalchemy.org/) + `asyncpg`
- **Таблиці:** [gspread](https://docs.gspread.org/) + Google Service Account
- **Веб-сервер:** `aiohttp` (healthcheck / ping ендпоінт для Render або UptimeRobot)
- **Деплоймент:** Docker, Docker Compose, Render.com (Blueprint `render.yaml`)

## 📊 Структура Google Таблиці

| Колонка | Назва поля | Опис |
|---------|------------|------|
| **A** | Позначка часу | Дата та час реєстрації (Київський час) |
| **B** | ПІБ | Повне ім'я учасника |
| **C** | Юзернейм | @username у Telegram або контакт |
| **D** | Університет | КПІ ім. Ігоря Сікорського |
| **E** | Факультет | ФІОТ |
| **F** | Група | Академічна група (напр. ІП-55) |
| **G** | Формат | **Офлайн** або **Онлайн** |
| **H** | Правила | Згода з правилами (Так) |
| **I** | tg_id | Telegram ID користувача для зв'язку та оновлень |

## ⚙️ Налаштування та запуск

### 1. Встановлення залежностей
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Змінні оточення (`.env`)
Створіть файл `.env` на основі `.env.example`:
```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
BD_ENGINE=postgresql+asyncpg://user:password@host/dbname?ssl=require
SUPER_ADMINS=123456789,987654321
LOG_SHEET_NAME=Лекція Студрада ФІОТ 2026
SHEET_URL=https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID
GOOGLE_CREDENTIALS_JSON=
```

### 3. Локальний запуск бота
```bash
python main.py
```

### 4. Запуск через Docker Compose (локальна PostgreSQL + бот)
```bash
docker compose up --build -d
```
